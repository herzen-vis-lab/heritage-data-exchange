# ADR 0001: Бутстрап сети без центрального оператора

- Статус: предложено (proposed), v0.1.0
- Дата: 2026-09-07
- Область: правила `node.registration`, `classifier.sync`, подписка на группы

## Контекст

Протокол заявляет федеративную топологию без центрального оператора, однако
правила требуют существования `federation_registry` (регистрация узлов) и
реестра классификаторов/групп подписки. Пока не определено, кто ведёт эти
реестры и как узел впервые узнаёт о других узлах, сеть не может стартовать:
это скрытый допуск модели, а не косметика.

## Рассмотренные варианты

1. **Центральный реестр** (реестровая топология) — противоречит принципу
   «без оператора», отвергнут.
2. **Подписанные снапшоты реестра в git-репозитории** (dogfood: реестр —
   такой же артефакт, как схемы и правила; подписи GPG/SSH на снапшотах;
   обновление — pull request, конфликты разрешаются явно).
3. **did:web / web of trust** — перспективно для транспортного слоя, отложено
   до реализации транспорта.
4. **P2P-DHT** — избыточно для целевого масштаба (десятки узлов), отложено.

## Решение

На этапе прототипа реестр узлов и реестр классификаторов существуют как
**подписанные снапшоты в git-репозитории федерации** (вариант 2). Каждая
запись узла: `federation_node_guid`, `federation_node_url`, публичный ключ
(для будущей подписи конвертов), контактная информация, подпись предыдущего
снапшота. Смена снапшота — явный коммит с историей. Никакой узел не владеет
реестром единолично: форк + pull request — механизм согласования, конфликт
разрешается правилами сообщества (как в этом репозитории).

## Последствия

- Реестр — артефакт, а не орган: согласуется с принципом `artifacts_not_organs`.
- Снимается «проблема курицы и яйца» регистрации: первый снапшот создаёт
  учредитель-федератор, далее сеть растёт через согласованные обновления.
- Требуется практика ротации ключей и процедура исключения узла (злонамеренного
  или неактивного) — оформить до перехода к транспортному слою.
- Не решено: доверие к классификатору (кто объявляет новую версию словаря) —
  предмет отдельного ADR при выпуске публичного классификатора.
